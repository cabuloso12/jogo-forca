# 🎮 Jogo da Forca em Python

Um clássico Jogo da Forca interativo desenvolvido em Python para rodar diretamente no terminal. O projeto conta com seleção de temas, sistema de pontuação dinâmico, validação de entradas do usuário e arte em texto (ASCII Art) para ilustrar o progresso do jogador na forca.

---

## ✨ Funcionalidades

* **Seleção de Temas:** Escolha entre Jogos, Tecnologia, Escola ou Filmes.
* **Interface Visual:** Gráficos em ASCII que mudam conforme o jogador perde vidas.
* **Validação Inteligente:** Bloqueia palpites repetidos, números, caracteres especiais ou palavras inteiras.
* **Sistema de Pontuação:** Ganhe +10 pontos por acerto e perca -2 por erro (sem pontuações negativas).

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Biblioteca Nativa:** `random` (para sorteio de palavras)

## 🚀 Como Executar o Projeto

### Pré-requisitos
Você precisa ter o **Python 3** instalado em sua máquina.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd nome-do-repositorio
   ```

3. **Execute o jogo:**
   ```bash
   python jogo_da_forca.py
   ```

---

## 🎲 Como Jogar

1. Assim que o programa iniciar, digite o nome de um dos **temas disponíveis**.
2. O terminal exibirá os traços `_ _ _` correspondentes ao tamanho da palavra secreta.
3. Digite uma letra por vez e pressione `Enter`.
4. Você começa com **6 vidas**. O jogo termina se as vidas zerarem ou se você adivinhar todas as letras.
